# Executor

The executor will allow to run lua inside lua, or any other language.

A frontend will be used to get the Bytecode that the executor runs.

To most important thing is I want to be able to call a function generated by this like a normal lua function, and this is possible.

```lua
local context = {}
local fn = execute(context, {6, {}, {{5}}}) -- defining a function that returns anything that is passed to it.
-- this is equivalent to `function(...) return ...`
-- now to call this function.

fn() -- this is it.
assert(fn(22) == 22) -- this will not assert, because the function will return 22.
local a, b = fn(2, 3) -- this will return the tuple that was pass in.
assert(a == 2)
assert(b == 3)
```

If you want to call a function is like this.

```lua
local context = {print = print}
local show_hello_world = execute(context, {6, {}, {{8, {"print"}, {{7, "Hello World!"}} }} })
show_hello_world() -- stdout: `Hello World!`
```

By writing manual bytecode you can return a module.
There are to methods, you can return a function that returns a table or you can have a tuple that has a block and the generates a table. 

function module:
```lua
local context = {}
local module_as_function = execute(context, {6, {}, {{3, {{7, "a"}}, {{7, 32}} }} })
local module = module_as_function()
-- module == { a = 32 }
```

module like lua:
```lua
local context = {}
local module = execute(context,
{
    6,
    {},
    {
        {1, {"foo"}} -- foo will not be inside context, if this is remove the foo can be accessed from context after execute.
        {2, {{"foo"}}, {{7, 32}}} -- this is like `foo = 32`
        {3, {{7, "a"}}, {{4, {{"foo"}}}} }
    }
})
-- module() == { a = 32 }
```

table:
```lua
local context = {}
local tb = execute(context, {3, {{7, "a"}}, {{7, 32}} })
-- tb == { a = 32 }
```


- If/`?` has implicit return.

- functions/`F` has implicit return.

## Bytecode

```luau
type Path =
{[number]: number | string | Expr }
```
If the first path segment is a number, then will be used as a temp value.

### 1 Define
```luau
type Define = {
    [1]: 1,
    [2]: {[number]: string}, -- names
}
```
Used to define what names are in this scope.
Equivalent to Lua `local a, b, c`

### 2 Set
```luau
type Set = {
    [1]: 2,
    [2]: {[number]: Path}, -- paths
    [3]: {[number]: Expr},
}
```
Used to set variabiles in the local stack and temps.
Equivalent to Lua `a, b, c = 1, 2, 3`

### 3 Table
```luau
type Table = {
    [1]: 3,
    [2]: {[number]: Expr}, -- keys
    [3]: {[number]: Expr}, -- values
}
```
This will result into a table put onto the stack.
Equivalent to Lua `{["a"] = 1, ["b"] = 2, ["c"] = 3}`

### 4 Read
```luau
type Read = {
    [1]: 4,
    [2]: {[number]: Path}, -- to read
}
```
Will add the vaules inside those paths onto the stack.
Equivalent to Lua `a`

### 5 Variadic
```luau
type Variadic = {
    [1]: 5,
}
```
Put all the variadic values into the stack.
Equivalent to Lua `...`

### 6 Function
```luau
type Function = {
    [1]: 6,
    [2]: {[number]: string}, -- argument names
    [3]: {[number]: Expr}, -- what the function should do
}
```
Implicit return function, this is a function object.
Equivalent to Lua `function() return end`

### 7 Insert

### 9 If
```luau

    [1]: 9,
    [2]: Expr, -- condition
    [3]: Expr, -- evaluated when the condition evaluates to true
    [4]: Expr, -- evaluated when the condition evaluates to false
}
```
Implicit return if, the condition that will be evaluate will have the values put onto the stack.
### 10 While
```luau
type While = {
    [1]: 10,
    [2]: Expr, -- condition
    [3]: {[number]: Expr},
}
```
A while loop, that is scoped like in Lua.
In every iteration it has a new stack.
The `Break` Expr will only block the next `Expr` after that, any `Expr` will be evaluated fully.
